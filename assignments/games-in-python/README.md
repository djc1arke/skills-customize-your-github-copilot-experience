
# 📘 Assignment: Games in Python

## 🎯 Objective

Build a Hangman-style word-guessing game using Python strings, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description

Create a game that randomly selects a hidden word and allows the player to guess it one letter at a time before running out of attempts.

#### Requirements

Completed program should:

- Randomly select a word from a predefined list.
- Accept letter guesses from the player.
- Display the current progress using underscores for unguessed letters, such as `_ _ _`.
- Track the number of incorrect guesses remaining.
- End when the player guesses the word or runs out of attempts.
- Display a message indicating whether the player won or lost.
